### The pipeline (run this loop per macro; document as you go)

2. **LVS**: does it pass? If no, fix the layout and repeat until LVS passes. If yes → (3).
3. **DRC**: does it pass? If no, fix the layout, then re-check **both LVS and DRC** until
   both pass. If yes → (4).
4. **Post-layout (PEX) verification**: does Layout+PEX match the schematic's performance
   to within **±1%**? If yes → DONE. If no, adjust (sizing, parasitic compensation, etc.)
   until it does — **without breaking LVS or DRC**. **If you add any element to optimize
   the layout, add it to the schematic too** (so schematic↔layout stay LVS-consistent and
   the SPICE reference stays valid).
