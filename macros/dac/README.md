# `dac` macro (analog) — 4-bit current-steering DAC

Converts the digital control word `dac_code[3:0]` (from [`../fll_digital`](../fll_digital))
into a bias current for the [`../ring_oscillator`](../ring_oscillator). Binary-weighted
**true current steering**: each unit PMOS source always conducts and is steered to the
output (bit = 1) or a dump node (bit = 0). Output current `I(iout) = code * IREF`.

Schematic-level (pre-layout), ihp-sg13g2. No layout yet.

## Files
- `spice/dac4.spice` — subckt `dac4 VDD VSS b0 b1 b2 b3 iout` (reference mirror + complement
  inverters + 4 binary-weighted steering cells + dump diode). Reference current `IREF`
  is an **ideal** source for now (a real resistor/bandgap reference comes later).
- `schematic/xschem/dac4.sch` — Xschem schematic (same circuit, for visualization;
  generated by `scripts/gen_xschem.py`, validated to netlist identically to the SPICE).
- `testbenches/spice/tb_dac4.spice` — DC characterization: code 0→15 → output current.

## Characterized (ngspice, mos_tt, 1.5 V), IREF = 2 µA
| code | I_out (µA) | | code | I_out (µA) |
|---|---|---|---|---|
| 0 | ~0 | | 8 | 16.5 |
| 1 | 2.07 | | 12 | 24.7 |
| 4 | 8.27 | | 15 | 30.8 |

Monotonic, LSB ≈ 2.05 µA. Note: code 0 ⇒ ~0 current ⇒ the ring oscillator stops; use
codes 1..15 (adding a small always-on floor current is an easy future enhancement).

## Run (inside the container, via `../../run.sh`)
```
ngspice -b testbenches/spice/tb_dac4.spice          # code -> current
```
Visualize: `xschem schematic/xschem/dac4.sch` (host display or noVNC :1).
